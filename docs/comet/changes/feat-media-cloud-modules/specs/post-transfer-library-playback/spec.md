# 转存后入库与播放（弱耦合后续）

## 目的

规定 CloudSaver「想看」成功之后，到用户可在外部播放器观看之间的 **产品边界与分阶段行为**。本 capability 与 `cloudsaver-service` 配套：获取成功在 CS 模块；入库管道在用户基础设施；播放入口在 App 配置层。

## 端到端阶段

| 阶段 | 责任方 | P0 App 行为 |
|------|--------|-------------|
| 1. 转存到网盘 | CloudSaver + Homelab 客户端 | 必须完成并报告 |
| 2. STRM/链接生成与同步 | 用户可替换工具（定时轮询等） | 不调用；可文案说明 |
| 3. 媒体库出现条目 | Emby / Jellyfin 等 | 不调用扫库 API（P0） |
| 4. 播放 | SenPlayer 等外部播放器 | 打开可配置库 URL |

## P0 行为要求

- 成功语义停留在阶段 1。
- 向用户说明阶段 2–3 可能延迟（定时同步、刮削）。
- 提供阶段 4 的入口：`libraryOpenURL`。
- 扩展点默认 NoOp，便于日后通知/探测而不绑死品牌。

## P1 行为要求

- 任务/历史便于用户回顾「已转存、可去库查看」。
- 设置项：库 URL、可选「预计同步说明」。

## P2+ 行为要求（方向）

- 可选媒体库探测与深链；失败降级。
- 可选立即同步适配器；与可替换 STRM 工具解耦（接口中性命名）。
- 不将 MoviePilot 或某一 QMS 实现写死为唯一管道。

## 可替换性不变量

- 更换 STRM 工具、改为 Jellyfin、去掉 Emby 反代：只要网盘仍被转存且库 URL 可配，**不必修改获取状态机**。
- 禁止把「可播」定义为 P0 硬验收，除非引入并验证可靠探测。

## 验收

- P0：与 `cloudsaver-service` 中「转存后 → 打开库」条目一致。
- P1/P2：随实现单独验收，不阻塞 P0 除非同 change 声明交付。
