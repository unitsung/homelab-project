# CloudSaver 服务模块（Homelab iOS）

## 目的

为 Homelab iOS 提供与 **OpenList** 同构的 **CloudSaver** 服务连接能力：用户管理自建 CloudSaver 实例，在 App 内完成网盘分享资源的 **搜索** 与 **一键转存（想看）**，并在转存成功后以弱耦合方式引导 **打开流媒体库** 供外部播放器使用。

本 capability 描述归档后系统应具备的完整行为（P0 必须；P1/P2 在文中标注）。

## 用户与场景

- **主用户：** 以网盘分享（115 / 夸克等）为主要片源、已自建 CloudSaver 的 Homelab iOS 用户。
- **主场景：** 手机上搜索片名 → **海报墙浏览结果** → 点想看 → 资源进入自己的网盘预设目录 → 稍后在 Emby/Jellyfin + SenPlayer 观看。
- **非场景：** MoviePilot 式全站管理、内置播放、完整网盘文件树管理、依赖 TMDB 等独立海报库作为 P0。

## 服务注册与实例

### 必须

- 存在 `ServiceType` 用例表示 CloudSaver（rawValue / 备份键跨编码稳定，如 `cloudsaver`；显示名「CloudSaver」或产品文案约定名）。
- 支持多实例：URL、可选 fallback URL、用户名、密码、自签名证书开关；凭据存 Keychain。
- 登录/连接校验：调用 CloudSaver 登录接口获取 token；token 过期可按 OpenList 类似策略重新登录刷新并写回存储（若实现回调）。
- 添加服务列表、导航入口、图标与中英文案与现有服务一致层级。
- 备份导出/导入识别该服务类型键。

### 不得

- 将作者内网地址、真实密码、真实目录 CID 硬编码进仓库默认值。

## HTTP 客户端

### 必须

- `CloudSaverAPIClient`（或等价 actor）经 `BaseNetworkEngine` 访问用户配置的 base URL。
- 至少支持（路径以用户 CloudSaver 版本为准，以下为已验证参考契约，实现可适配等价路径）：
  - 登录：`POST` 用户登录 → Bearer token
  - 搜索：`GET` 搜索关键词（支持分页/加载更多字段若服务返回 `hasMore` / `lastMessageId` 等）
  - 115：分享信息与转存到指定 `folderId`/CID
  - 夸克：分享信息与转存到指定目录（含服务所需 token 字段）
- 将搜索结果规范为 App 模型，**必须解析并保留海报字段**（参考契约中的 `image` 或等价封面 URL），以及标题、描述、云盘类型、shareCode、receiveCode、体积/频道等；缺省可空但模型字段存在。
- 错误映射为用户可读信息（未配置、未登录、分享无效、目录未配置、网络失败等）。

### 参考来源

- 仓库外 `cloudsaver-proxy` 中已逆向的调用顺序与字段映射可作为实现参考，**不得**作为运行时依赖。

## 豆瓣榜单（默认海报墙）

### 必须

- 模块默认进入 **豆瓣榜单** 分段（对应网页 `/douban`）。
- 调用官方 `GET /api/douban/hot?type=&tag=&page_limit=&page_start=`（需 Bearer token）。
- 默认 `type=movie`、`tag=热门`。
- 分类 chips 至少覆盖热门/最新/冷门佳片电影与热门电视剧等常见类目。
- 海报字段使用 API 的 `cover`；展示评分 `rate` 角标。
- 点击海报：以片名跳转 **资源搜索** 并调用 `/api/search`（对应网页 `/resource`）。

## 搜索与想看 UI

### 必须

- 服务主界面提供关键词搜索。
- **海报墙（P0 主结果形态）：**
  - 搜索成功后以 **网格海报墙** 展示结果（非纯文本列表作为唯一形态；列表可作为辅助，但 P0 须有墙式布局）。
  - 每个格子以 **CS 逆向搜索 API 返回的封面 URL（如 `image`）** 加载海报；异步加载、占位与加载失败回退（占位图 + 标题仍可读）。
  - 海报数据 **只来自 CloudSaver API 响应**，P0 **不得**依赖 TMDB/豆瓣等第三方海报 API 作为必选链路。
  - 格子上或详情中可展示：标题、云盘类型（115/夸克等）、体积/来源等可用字段。
  - 若 API 支持 `hasMore` / `lastMessageId`（或等价），海报墙支持加载更多并追加格子。
- 「想看」动作：对选中结果（从海报墙或详情）发起转存。
- 默认使用 **预设目标目录**（按分类：至少支持电影 / 剧集 / 动漫或等价可配置槽位；实现可用标题启发式选择分类，与参考 proxy 类似，且允许用户在设置中覆盖规则优先级）。
- 转存过程有进行中反馈；结束后成功或失败明确。

### 不得

- P0 强制每次进入完整文件夹树选择（P1 可在详情中提供覆盖目录）。
- P0 用纯文字列表替代海报墙作为唯一结果 UI。
- P0 为海报墙引入必须在线的第三方元数据/海报服务。

## 目录与多盘配置

### 必须

- 实例或服务级设置可配置：
  - 115：电影 / 剧集 / 动漫（或统一默认 + 可选细分）目标 folder/CID
  - 夸克：同上（服务支持时）
- 转存目标盘由结果云盘类型决定：115 链走 115 目录，夸克链走夸克目录。
- 对应目标未配置时：**拒绝转存**并提示配置，不得静默使用空或内置他人 CID。

### P1

- 详情页临时覆盖本次转存目录。
- 双链并存时的用户可选优先盘策略。

## 任务状态（获取层）

### 必须

- 单次想看可建模为任务或等价 UI 状态，生命周期包含：
  - `transferring`：转存进行中
  - `transferred`：CloudSaver 确认转存成功
  - `failed`：失败及原因
- **主路径成功 = `transferred`。**

### 不得

- 使用绑定具体 STRM 产品的状态名（如 `qms_syncing`）作为核心状态机。
- 在无可靠信号时展示「正在生成 STRM / 正在扫描 Emby」类进度并当作已验证事实。

## 转存成功后：入库与播放（弱耦合）

本节描述 **P0 必须的用户可见行为** 与 **后续增强方向**。

### 管道模型（事实）

```text
transferred → 用户网盘目录
    →（用户可替换）STRM/同步工具（如定时轮询）
    → Emby 或 Jellyfin 等流媒体服务器
    → SenPlayer 等外部播放器打开库地址
```

- 当前用户环境可使用 QMediaSync 等定时同步；该工具 **无可靠入站「立即同步」正式能力** 时，App 不得依赖立即入库。
- 同步工具、反代、302、STRM 生成器均可替换；App 不绑定品牌。

### P0 必须

1. `transferred` 后展示说明：资源已在网盘；媒体库将由用户侧同步机制更新（可配置提示文案和/或预计间隔，**仅文案**）。
2. 可配置 **`libraryOpenURL`**（Emby / Jellyfin 或用户指定的库入口）。
3. 提供 **「打开媒体库」**（文案可调整）：在已配置 URL 时通过系统打开（SenPlayer 可处理 Emby 地址的场景由用户环境决定）。
4. 未配置 `libraryOpenURL` 时，转存主路径仍可用。
5. 提供扩展点（协议/回调/NoOp 实现）供转存成功后可选通知；**默认实现为空操作**，不调用 QMediaSync 或其它 STRM API。

### P1

- 近期想看/任务历史列表。
- 同步说明与库 URL 的设置项体验完善。

### P2+

- **就绪探测：** 可选调用媒体服务器 API 按标题等查询是否出现；须声明服务器类型；失败降级为仅 `transferred`。
- **深链：** 打开具体条目（若播放器/库支持）。
- **立即同步适配器：** 可选、可失败；不得使转存成功回滚为失败。
- **旁路获取：** 磁链 → qBittorrent；115 离线；与 CS 想看分类型，不得混为一个无差别按钮语义。
- **追番：** Mikan / AutoBangumi 等独立能力，不并入本模块 P0 状态机。

### 明确非目标（本 capability）

- MoviePilot 作为后端或必装依赖。
- 生产环境 LLM Agent 作为转存/入库运行时。
- Immich。
- Android 客户端（本 change）。
- 完整 Emby/JF 管理功能。

## 与 quark-auto-save

- 用户可继续部署 quark-auto-save 做夸克追更/定时转存。
- 本模块点播主路径以 **CloudSaver API 直接转存** 为准。
- P0 **不要求** Homelab 调用 quark-auto-save HTTP API。

## 安全与隐私

- 密码与 token 仅存 Keychain。
- 日志、规格、验证证据不得包含明文密钥、完整 cookie、真实 CID 样例。
- 自签名证书行为与现有服务开关一致。

## 可复制性

- 任意用户在自有 CloudSaver 与自有目录配置下应能使用本模块。
- 验收不依赖作者家庭的 QMS/反代/特定内网拓扑。

## 验收标准摘要

| ID 概念 | 标准 |
|---------|------|
| 注册 | 可添加 CloudSaver 实例并持久化凭据 |
| 搜索 | 关键词返回可展示结果；模型含海报 URL 字段 |
| 海报墙 | 结果以网格海报墙展示；有 image 时显示封面，无则占位+标题 |
| 想看-115 | 配置 115 目录后转存成功或可读失败 |
| 想看-夸克 | 配置夸克目录且 CS 支持时同上 |
| 目录守卫 | 未配置目录不可静默成功 |
| 状态 | 存在 transferred/failed 语义 |
| 打开库 | 配置 URL 后可触发打开 |
| 无库 URL | 仍可转存 |
| 无下游绑定 | 无 QMS/MP 硬依赖 |
| 测试/编译 | iOS 单测覆盖关键逻辑；工程可编译 |

## 实现提示（非强制）

- 对照 `OpenListAPIClient`、OpenList 登录与导航挂载方式。
- 分类启发式可参考历史 proxy 的 title 规则，但目录 ID 必须来自用户配置。
