## 1. 默认可见性

- [ ] 1.1 在 `SettingsStore`（或等价处）定义默认隐藏集合（含 `sonarr`）
- [ ] 1.2 仅在「从未保存过 hiddenServices」时应用默认集合；已有键不覆盖

## 2. 设置可恢复

- [ ] 2.1 确认设置/媒体排序或隐藏 UI 可取消隐藏 Sonarr
